# TourBots.AI — Development List
**Source: codebase audit, July 2025**

---

## 1. Lead capture wiring
- Build a lead capture form that can be pushed into the chat window during a conversation, triggered by the AI at the right moment.
- Wire it into the existing lead pipeline — `handleLeadDataChange` and `sendLeadNotificationEmail` already exist but are never called. Connect them.
- Confirm `leads` table has a proper tracked migration in `sql/` — currently missing, needs adding regardless of where the table originated.
- Sort out the dashboard once leads are flowing — surface real conversion data instead of the current hardcoded zero (`app/api/app/dashboard/route.ts`).
- AI lead scoring engine already exists (`ai-scoring-service.ts`, `lead-scoring-service.ts`) — once capture is wired up, make sure scoring is called as part of that same flow.

## 2. Zapier / Make / n8n connection
- Build the integration into the TourBots platform itself so customers can connect their own Zapier, Make, or n8n account.
- This becomes the AI's action layer — triggering actions in a customer's CRM, sending notifications, logging leads, whatever workflow they set up on their end.
- Covers the "automate the busywork" capability without building bespoke native integrations for every CRM.
